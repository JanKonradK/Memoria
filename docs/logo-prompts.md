# Memoria game icon prompts

This file holds one ready-to-paste image prompt per preset game in Memoria, for previewing a new round game icon design. To use it, open ChatGPT's image generator, paste one prompt at a time from the sections below, and ask for a 1024x1024 square image. The hex colours in each section are proposals written from memory of each game's logo, not verified values, so check them against the real logos before relying on them. The "current preset" column shows what the app's preset uses in code now, for comparison.

## Shared style

- Round icon, centred, on a solid near-black background (#0c0d0f).
- Flat, clean, UI-icon style. No 3D, no bevels, no gloss, no drop shadows.
- No characters, no mascots, no official logo artwork, no extra text beyond the name.
- The name is set in the Google font Vujahday Script, light cream text (#f5efe2), centred inside the circle, on exactly two lines (or one line where a section says so).
- The ring is the only other element: an outer ring made of exactly two colours. The two bands interlock and chase each other around the circle like a yin-yang, or two dragons dancing nose to tail. Each colour's band tapers from thick to thin. Nothing sits inside the ring except the name. The ring suggests rotation.
