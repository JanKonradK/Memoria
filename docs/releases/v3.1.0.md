# Memoria 3.1.0

- Memoria updates itself. The Windows and Android apps check GitHub for a new release, show what changed, and install it after you confirm. Find it in **Settings → Updates**, or follow the notice when a new version is found.
- The Android app is now part of every release.
- Today holds the Games overview, with flat game rows, round game logos and each game's name in its own typeface.
- A game's page shows tracking on the left and events on the right. Its actions sit in the heading.
- Events open on a quick view. Pin the ones you care about, and tick multi-part events off one part at a time.
- Changed numbers count to their new value on Today and in Tonight.
- HoYoLAB accounts are read without a browser by default. Automatic readings and Play mode have been removed.
- Memoria asks before a first sync combines two sets of games, and before every delete or discard.
- The event feed runs through October 11.

The first update on Android asks you to allow Memoria to install apps.
