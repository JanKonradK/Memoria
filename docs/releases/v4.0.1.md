# Memoria Beta 0.4.0.1

- Fix: once your data passed about 900 KB, the PC stopped saving and syncing it, and Memoria couldn't close to install an update. Devices now sync up to 8 MB.
- Restore checkpoints keep more history when your data is large.

**Coming from 0.3 on a PC?** If Memoria says "Data is close to the 1 MB limit" when you update, the update can't install itself. Download `Memoria-win-x64.zip` below. End Memoria in Task Manager, unpack the zip and run `Add Memoria to Start Menu.cmd`. Your data is kept.

Everything from Beta 0.4 applies: update the PC and the phone together, then pair your phone with the PC again, once.
