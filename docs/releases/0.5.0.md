# Memoria Beta 0.5.0

**Notes, properly.** Notes are now cards: as many as you like for each game, plus **General** notes that belong to no game. Each one can have a title, a colour (its game's or one of six others) and a pin to the top. A line that starts with `- [ ]` becomes a box you can tick, and the note shows how many are done. A note's menu also moves it to another game, duplicates it or deletes it, with **Undo** for a few seconds. On the Notes page, filter by game, sort by newest, last edited or title, group the notes under their games or show them as one wall, and switch to a compact size. Each game's old notes box is now that game's first note. Notes sync between your devices like everything else.

**A month you can read.** **Calendar → Month** now lists what **ends** on each day, coloured by game, and how many events start. Days where more unfinished events end are shaded more strongly, so the busy days stand out. A line above the grid shows how many events end this month, how many are left and which day is busiest. The panel for the chosen day also lists what is **still running** that day, so a quiet day still shows you something to do.

**Ending soon helps you get ahead.** A line at the top says how today and this week stand. Below it, a strip of the next 14 days shows how many events end on each one, so the busy days are visible in advance. **Do next** suggests four events worth doing now, each with its reasons: its last day, a busy day coming up, that you've already started it, or the currency it pays.

**Icons you choose.** In **Settings → Appearance**:

- **Icons**: six sets for the navigation. **Outline**, **Solid** and **Minimal** (abstract marks) are single-colour. **Colour** puts each place's own colour under its lines and **Tiles** puts each icon on a coloured square. **Pixel** is 8-bit pixel art.
- **Game icons**: Coin, Badge, Initial or a Symbol you pick (star, moon, bolt, flame, crown and more). Set one style for every game, or give any game its own.

Both choices are kept on each device.

- **The sidebar on a PC** now runs Today, Calendar, Notes and Games, with Settings at the bottom. Each place is a small icon with its name, and only the current one is highlighted. Alt+1 to Alt+5 follow the order on screen.
- **A game's page on a wide screen** gives events more room and energy less, so long event names are no longer cut off.
