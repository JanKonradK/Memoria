# Memoria Beta 0.6.0

**Opt-in live numbers from HoYoLAB and SKPORT.** Sign in under **Settings → Connections** to read **HoYoLAB Real-Time Notes** (Genshin Impact, Honkai: Star Rail, Zenless Zone Zero — resin/power/charge, reserves, dailies, weeklies, endgame cycles and daily check-in status) and **SKPORT** (Arknights: Endfield). Sign in through an isolated browser window that reuses your saved session, pair Chrome, Edge or Firefox using the bundled **Memoria Browser Connect** extension with a one-time 6-character code, or paste a browser session. Credentials stay sealed on-device with Windows DPAPI or the Android Keystore and are never written to backups or sync. HoYoLAB connects through `sg-public-api` with `bbs-api-os` fallback and updated OS request signing so HSR notes and endgame read reliably.

**Codes tab and one-tap claiming.** Each game page now has a dedicated **Codes** tab holding both calendar codes and your own saved codes. When a game is linked to HoYoLAB, **Claim** redeems codes and claims today's HoYoLAB daily check-in in a single tap, automatically ticking the daily or marking the code redeemed with Undo.

**Multi-region, multi-field screenshots.** Press `Ctrl+Shift+M` (or use **Snip**, `Shift+S`, the Windows tray menu, or Android Share) to read **Bars & reserves**, **Tasks & dailies**, **Endgame cycles** and **Savings** together in one pass:

- **On Windows**, drag up to **8 numbered regions** on the frozen screen (or press `Enter` right away for the whole screen), previewed as a stacked contact sheet. Small HUD text is upscaled 2× before OCR, split label/value lines pair cleanly, and a collapsible **Recognised text** view lets you check what Windows OCR read.
- **Confirm before saving**: edit or add extra bars, tasks, endgame cycles or savings directly in the sheet, snip another area to merge into the open sheet without losing edits, see warnings on screenshots older than your last reading, and undo the entire batch at once.

**Pull history import and PC cache scan.** On **Pulls**, import offline UIGF v2–v4 or WuWa JSON files on any device, or select **Read from PC game** on Windows to scan your local game cache read-only for Genshin Impact, Honkai: Star Rail, Zenless Zone Zero and Wuthering Waves.

**A wider infinity-to-M mark, finishes and backdrops.** The app logo, Windows icon and Android launcher icons now carry a wider infinity-to-M ribbon with faceted shards. In **Settings → Appearance**, pick **Logo colours**, **Logo shading**, **Logo tiles** and **App backdrops**, plus a non-blocking **Preview Store locks** switch to see which finishes are earmarked for Memoria Pro.

- **Sync away from home without a VPN:** optionally self-host the encrypted Cloudflare mailbox relay (`relay/`) and paste its address under **Settings → Device sync → Sync away from home** alongside Tailscale and Wi-Fi sync.
- **Wide PC Track layout:** a game's **Track** tab arranges bars, tasks and events into two balanced columns on wide screens.
- **Polish & fixes:** Undo toasts pause while hovered or focused, switching away from Memoria keeps open note editors open, mobile Calendar week swipes no longer trigger page swipes, `Alt+4` skips deleted games, CRLF checklist notes tick cleanly, and light-mode warning text meets WCAG AA contrast across active rail items.
