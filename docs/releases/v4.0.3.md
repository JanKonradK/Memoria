# Memoria Beta 0.4.0.3

**Phone and tablet sync**

- Found why phones could not connect: Windows Firewall was blocking them. Settings → Device sync on the PC now checks this and shows what is wrong.
- When Windows treats your home Wi-Fi as a public network, **Allow phones on this Wi-Fi** marks it private and lets Memoria through, after Windows asks for permission. When only the firewall rule is missing, **Allow through Windows Firewall** adds it, also for the portable copy wherever you unzipped it.
- The phone now tries the PC's Wi-Fi address first, not addresses from WSL or Hyper-V that it can never reach.
- A **Devices** list shows every connected device on the PC and on each phone or tablet: which is connected now and when the others last synced. Disconnect any of them from the PC.
- Phones and tablets now get their own names, so the list tells them apart.

**Servers and accounts**

- Memoria no longer picks a server for you. Choose it when you add a game.
- Each game lists its own servers, such as TW, HK, MO for HoYo games and HMT and SEA for Wuthering Waves. Any other timezone is still available.
- First-run setup: tap each server you play on to add an account there. Tap a server again for a second account on it, or add as many as you like on different servers.
- Settings and the game editor use the same server list.
