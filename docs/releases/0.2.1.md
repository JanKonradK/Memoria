# Memoria Beta 0.2.1

**Windows updates install again.** Memoria downloaded updates but could not install them: the installer started inside the folder it had to replace, and Windows refuses to move a folder in use. It now starts outside it, waits a few seconds for Memoria's helpers to close, and writes `%APPDATA%\memoria\updates\install.log` if anything still goes wrong. If an earlier update failed for you, this one installs normally from **Settings → Updates**.

- **Quests:** the search bar stays under the menu on wide windows and scrolls away on a phone, where it took a third of the screen.
- **Settings → Reminders:** the list of reminder styles sits under its heading.
