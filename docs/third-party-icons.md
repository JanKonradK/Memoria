# Third-party icons

The place icons (Settings → Appearance → Icons) in the Outline, Solid, Colour, Tiles and Minimal sets are copied from Phosphor Icons by app/scripts/build-nav-icons.mjs into app/src/nav-icon-art.ts. The Pixel set is drawn in app/src/nav-icons.tsx.
