# Event feed audit — 17 September 2026

Checked all nine supported games for current and announced events. This is a source audit, not a guarantee that every account-specific offer is covered. Existing keys stay stable where possible. User edits and deleted events use the existing import rules.

## Urgent Genshin correction

Trial of the Bastion was missing. Official announcement 21816 gives 7 September 10:00 to 17 September 03:59, **server time**. The Europe deadline is 17 September 02:59 UTC (03:59 BST). The America deadline is 08:59 UTC. The Asia deadline is 16 September 19:59 UTC.

Starlight Voyage also has two deadlines: quests end 17 September 04:00 server time; reward claims end 21 September 03:59. The feed now shows both. These dates must not be combined into one reward-claim window.

## Remaining limits

- Genshin's newcomer selector depends on registration and has a personal 42-day window. It is not a universal dated event. Calendar events have dates but no exact hours.
- HSR's phase 2 close conflicts with maintenance. Realm of the Strange did not have a verified text schedule in the retrieved official feed. Some older mixed local/global rows still require review beyond this correction.
- WuWa's separate phase 2 weapon banner notice and next broadcast were not verified. No new weapon row was inferred from a third-party pull guide.
- NTE's next Beyond the Rails cycle and broadcast had no verified new schedule.
- LADS's next Hunter Contest after 21 September had no verified schedule.
- Uma's Transfer Request opening and Dream Team announcement lacked a complete window. Scout estimates remain silent.
- NIKKE's Champion Arena opening did not include a close. No close was invented.
- Endfield's next maintenance remains unconfirmed. Affected rows retain explicitly labelled placeholder ends with alerts off. The second Sanity Supply closes at different local times in Asia and Americas/Europe; the feed notes this and keeps alerts off because one row cannot represent both local closes.
- Existing broadcast forecasts remain forecasts. Web, social and community campaigns were outside the in-game feed scope.

## Search summary

Used Smart Search with fetch-first checks. Queried official notices and full publisher update text for all nine games, then used named mirrors or reposts where the original text was unavailable. Read the HoYo announcement API's text and picture lists, and inspected the official Genshin calendar image. HoYo `t_lc` means server-local time; `t_gl` means a global instant.

Direct fetches were empty or blocked for some sources. Endfield's official page succeeded through browser-backed fetching. ZZZ's official page returned a shell, so its publisher Steam notice mirror supplied the full schedule. NIKKE and WuWa used publisher-notice transcriptions. Search snippets alone were not used to enable new deadline alerts. Two delegated CLI attempts could read the repository but could not use their web or write tools; direct research supplied the findings above.

Added 60 event rows across eight games and corrected existing rows across the nine-game feed. Source keys are unique.

Validation passed: `npm run check` (448 tests, lint, formatting, types, build and PWA checks). Dashboard Closing and timeline agenda browser checks passed: nine passed, five skipped by their viewport rules. Regression coverage verifies server-specific Trial of the Bastion cutoffs and separate Starlight Voyage gameplay/claim windows.
